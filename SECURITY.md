# Security Policy

## Supported Versions

The following versions of JPM are currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of JPM seriously. If you believe you have found a security vulnerability in JPM, please report it to us by emailing **whomaderules@gmail.com**.

Please include as much information as possible to help us understand and fix the issue:

- Type of issue (e.g., buffer overflow, SQL injection, cross-site scripting, etc.)
- Full paths of source file(s) related to the manifestation of the issue
- The location of the affected code
- A proof-of-concept or exploit code if possible
- Any other information that might be relevant

We will acknowledge your report within 48 hours and provide a timeline for a fix. We ask that you do not disclose the issue publicly until a fix has been released.
